How it works — optional reading

This page explains how it works. You don't need it to use the board — it's for the curious.

Signal path

StageWhat it does
Voltage divider Brings ±614 V down to a level the ADC can see. The bottom of the divider goes to a reference voltage, not to ground — that's where the bidirectional range comes from
Shunt + Kelvin Turns current into voltage; the sense leads are routed separately from the current path, so solder resistance doesn't get into the measurement
Anti-aliasing filter The same time constant on both channels (2.86 ms / 2.90 ms). If they differed, the power error on reactive loads would be huge
16-bit ADC ×2 Voltage and current are sampled simultaneously in single-shot mode; the remaining 95 µs skew is removed in software
Power calculation Product per sample: avg(V×I). Not avg(V)×avg(I) — on a switching load that gives the wrong answer

Why these numbers

Sample rate 665/s The ADC's 860/s plus the I2C write-read time. Single-shot mode buys simultaneity at the cost of 23% of the rate
Filter 56 Hz Must stay below half the sample rate, otherwise high-frequency components fold into the band and can't be undone
Valid band 40–70 Hz The phase calibration stores a fixed delay, but what it corrects is a phase difference that changes with frequency. The two only match near the calibration frequency
Battery ≤ 38.5 V With the switch off, the whole battery sits across the MOSFET; the 55 V part was given a 70% margin

Verification

The whole design is tested on the computer. Every claim is backed by a test you can run; no number is typed in by hand.

Verification steps15
Automated checks900+
Circuit simulationngspice
Firmwareruns in an emulator

The measurement maths runs as the real firmware code on a bit-exact verified processor emulator — so what gets tested is the very code that will run on the board.

On top of that, every new claim goes through mutation testing: the relevant constant is deliberately broken and the test is shown to turn red. If it doesn't, the claim is empty and gets deleted.

The chain verifies the design, not a built board. Real component tolerances, temperature drift, leakage on the perfboard and noise can only be measured on the bench.
