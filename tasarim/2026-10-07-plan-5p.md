# 5P uygulama planı — panel telefonda

**Spec:** `tasarim/2026-10-07-5p-panel-telefonda.md` (K1–K19). Dal `5-android`, çalışma ağacı
`projeler/olcum-karti-android`. Yürütme: paralel alt ajanlar (ayrık dosyalar) + bütünleştirme bende
(kullanıcı devri, hafıza *hiz-alt-ajan*). Ajanlar git KULLANMAZ; commit'i bütünleştirici atar.

## Global kurallar

- Panel kaynağı (`arayuz3/`, `ortak/`) PC'de değişmeden çalışmalı: ortam kancası YOKSA davranış bayt bayt
  aynı. `node uretim/test_arayuz3.js` (B7) her panel değişikliğinden sonra YEŞİL; kuralları: tek satır
  import, `fetch(` argümanında `kartAdres(`, kart uçlarına doğrudan fetch yok (eslesme.js ve p0 satırı
  hariç), `toLocale*`/`Intl.*` yok, CSS'te yalnız belirteç, yeni metin sözlükten (EN eksik kilidi 272
  aşılmaz), açılış sözlüğü ≤ 19 500 B gzip, açılış kümesi dosya/bayt sınırları, `gonder('…')` komutları
  firmware'de var.
- Mobil: `npx vitest run` yeşil; Kotlin `android\gradlew.bat testDebugUnitTest` yeşil (bilinen ara sıra
  düşen `OzetEszamanTest` raporda adıyla).
- Yazma: kaçış içeren dosyaları heredoc ile yazma (Write/Edit). Python yama betiği `write_bytes`.
- Sır yok: parola / Wi-Fi adı / cihaz seri numarası hiçbir dosyaya.

```js
{

  //      body (string|Uint8Array), signal}. Dönüş: GERÇEK `Response` (new Response(bayt, {status, headers})).
  //      Ağ hatası -> reddeder (TypeError gibi), HTTP hatası -> Response.ok=false.
```

### P2 — Panel kancaları (ajan B) — yalnız `arayuz3/` + gerekirse `ortak/src/sozluk*.js`
- `app.js`: `const ORTAM = globalThis.__olcumOrtam || null;` (modül başı). ORTAM varsa:
  `TASIYICILAR.telefon = ORTAM.tasiyici`, `tasiyiciAdi='telefon'` zorla (kaydedilmez, seçicide yok),
  `kopruyuAlgila`/`swKur`/eski SW silme atlanır, `otomatikBaglanmali()` true; `kartIstek` →
  `ORTAM.istek`; `eslesmeHazirla()` → null; p0 → `ORTAM.p0()` (B7'nin p0 satırı kuralını koru — gerekirse
  B7'yi telefon dalını tanıyacak şekilde GENİŞLET, gevşetme); şerit görünürlüğü `ORTAM.serit(...)`;
  `Gb` gönderilince `ORTAM.komutGitti(metin)`.
- `ekran/esitleme.js`: kurucuya `ortam` enjeksiyonu (varsayılan `globalThis.__olcumOrtam`); kaynak
  `'telefon'`: `_depo`→`ortam.depo`, `akislar`→`ortam.akislar`, `esitle`→`ortam.esitle`, `akisSil`→
  `CalismaHatasi` ("kopyayı Bu telefon → Eşitleme'den sıfırla"), `esitlemeDurumu`→null. `kokenSinama`
  ORTAM varken false.
- `ekran/ayarlar.js`: `kopruKokeni` ORTAM varken false; `AYAR_BOLUMLERI`'ne yalnız ORTAM varken
  `telefon` ("Bu telefon", ilk sırada); bölüm açılınca `ORTAM.ayarBolumu()` → `markRaw` bileşen
  (pc_kopru deseni); ORTAM varken `baglanti`, `eslesme`, `depolama` bölümleri listede YOK.
  `TASIYICI_METIN.telefon` sözlükte.
- Dosya üretimi: `dosyaVer(ad, mime, bayt)` tek yardımcı (açılış kümesine yük bindirmeyecek yerde — örn.
  `ortak/src/disari.js` ya da yeni tembel modül); 6 yer onu çağırır; ORTAM varsa `ORTAM.dosyaVer`.
  Rapor yazdır: ORTAM varsa `ORTAM.yazdir()`.
- B7'ye yeni iddialar: (1) ortam yokken `TASIYICILAR` anahtarları {seri, akis, demo}; (2) panelin
  kullandığı `ORTAM.x` adları sözleşme listesinin alt kümesi; (3) dosya üretimi yalnız `dosyaVer`'de
  `a.download`; (4) telefon kipinde kart uçlarına `fetch(` yok. Panel tarayıcı testleri
  (`uretim/tarayici_canli.py`, `tarayici_kayitlar.py`) yeşil.
